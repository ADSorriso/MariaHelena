# Chá de Bebê da Maria Helena 🎀

Convite interativo com música, lista de presentes e painel privado da organizadora.

**Data:** 23/01/2027 às 15h. O local é enviado individualmente pelo WhatsApp.

## Publicação

1. Executar `APLICAR_NO_SUPABASE.sql` no Supabase do projeto existente.
2. Enviar os arquivos da raiz deste diretório para a **raiz** de `ADSorriso/MariaHelena`, branch `main`.
3. Confirmar a publicação em GitHub Actions e realizar testes de confirmação/reserva.

Leia `INSTRUCOES.txt` para detalhes. O MP3 está embutido no `index.html`, sem arquivo de áudio extra.

**Segurança:** apenas chaves públicas no `config.js`. Não colocar service_role, senhas ou tokens secretos no site.
